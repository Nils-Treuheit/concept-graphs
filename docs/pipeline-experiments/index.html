Broader Replica room0 run

One fixed-configuration pass covered 200 of 2,000 frames at stride 10 (10%). Detector, annotation, and CUDA mapping completed. The detector cache contains 4,502 detections; all 200 frames have relation and caption outputs, totaling 1,109 relation tuples and 3,606 caption records. Mapping took 30:12 in the CUDA frame loop and peaked at about 14.58 GiB total GPU use.

2,794final map tracks; 3,185 retained observations
48.3%of 211 repeated tracks contain differing class IDs
30 edgesall endpoint IDs and tags resolve; 29 “on top of”, 1 “under”

There are 31 tracks with duplicate frame IDs. Per-observation caption names differ from the final track class on 144/3,185 records (4.52%), across 102 tracks. Caption consolidation was disabled, so the map has no consolidated captions. No instance ground truth is available; these checks cannot establish association precision/recall or caption accuracy. The difference between 4,502 detections and 3,185 retained observations spans multiple filtering and projection stages; available artifacts lack counters to isolate it.

The 1,109 source relations and 30 output edges do not define a recall score: edges aggregate exact ordered object pairs and weak edges are pruned. Thresholds were not retuned. Full scene coverage and another scene remain open.

Optional experiments reviewed

Template retrieval, query VQA, and optional components

The matched held-out retrieval run used the five locally available ReplicaSSG test scenes (250 frames, 2,204 GT object views). On mask-isolated crops, SigLIP2 led cross-view identity top-1 (0.3966) and oracle graph triplet recall (0.3878); FG-CLIP2 led category macro AP (0.0403). Visual-only DINOv3 FP32 reached identity top-1 0.3800 and triplet recall 0.3265, while using 1.402 GiB peak reserved CUDA memory. Keep SigLIP2 as the map-association feature and FG-CLIP2 in the separate padded-proposal retrieval role; do not substitute DINOv3 for DINOde.

This is an oracle-mask representation comparison, not detector-backed map retrieval or end-to-end VQA. ReplicaSSG test data contains relation triples but no aligned natural-language questions or answers; generated questions would be a synthetic graph-query task. Earlier FP16 DINOv3 scores were invalidated after a CUDA diagnostic found non-finite embeddings. Only corrected FP32 scores are used. DINOde, EOVSAM, ObjEmbed, and T-REN could not be benchmarked because required method code/checkpoints were unavailable. SAM 3.1 has a cached checkpoint blob but no runnable project integration. Native COCO mask metrics remain blocked because prediction records and configured YOLOE checkpoints are absent.
