Detector, feature, and consolidation settings are fixed from the recorded component experiments. Qwen3.8 remains the provisional per-frame default because the shortlist evaluates schema reliability and agreement, not semantic truth. The map audit is descriptive because this scene has no ready-to-use instance IDs.

YOLOE prompting: the modernized masked pipeline uses text prompts via set_classes and the 200-name ScanNet class list (multiword labels are hyphenated). The COCO detector comparison uses text prompts from its 80 COCO categories. Neither path uses visual prompts or a prompt-free checkpoint. The proposed primary follow-up compares fixed labels, prompt-free discovery, and VLM scene-category prompts with paired open-scene quality and complete-pipeline latency. The VLM arm requires GPU co-residency and must stay within 10% of prompt-free latency; the prompt-free checkpoint is not yet available locally. The VLM arm will screen SmolVLM2, Qwen3.5, Florence-2, Gemma 4 E2B, LFM3-VL-2B, and Moondream 3.1 for structured scene categories and GPU co-residency. LFM3 documents full-weight BF16, not FP16. A separate RF-DETR-Seg M/L comparison is scoped as a closed-set COCO control, not an open-vocabulary replacement. A DINOv3-L feature-injection hybrid is recorded as a training-dependent research candidate; the DINO-YOLO preprint does not establish YOLOE/open-vocabulary mask gains. Association needs improvement

Broader Replica room0 run

One fixed-configuration pass covered 200 of 2,000 frames at stride 10 (10%). Detector, annotation, and CUDA mapping completed. The detector cache contains 4,502 detections; all 200 frames have relation and caption outputs, totaling 1,109 relation tuples and 3,606 caption records. Mapping took 30:12 in the CUDA frame loop and peaked at about 14.58 GiB total GPU use.

2,794final map tracks; 3,185 retained observations
48.3%of 211 repeated tracks contain differing class IDs
30 edgesall endpoint IDs and tags resolve; 29 “on top of”, 1 “under”

There are 31 tracks with duplicate frame IDs. Per-observation caption names differ from the final track class on 144/3,185 records (4.52%), across 102 tracks. Caption consolidation was disabled, so the map has no consolidated captions. No instance ground truth is available; these checks cannot establish association precision/recall or caption accuracy. The difference between 4,502 detections and 3,185 retained observations spans multiple filtering and projection stages; available artifacts lack counters to isolate it.

The 1,109 source relations and 30 output edges do not define a recall score: edges aggregate exact ordered object pairs and weak edges are pruned. Thresholds were not retuned. Full scene coverage and another scene remain open.

Optional experiments in progress

Template retrieval, query VQA, and optional components

The matched held-out retrieval run used the five locally available ReplicaSSG test scenes (250 frames, 2,204 GT object views). On mask-isolated crops, SigLIP2 led cross-view identity top-1 (0.3966) and oracle graph triplet recall (0.3878); FG-CLIP2 led category macro AP (0.0403). Visual-only DINOv3 FP32 reached identity top-1 0.3800 and triplet recall 0.3265, while using 1.402 GiB peak reserved CUDA memory. Keep SigLIP2 as the map-association feature and FG-CLIP2 in the separate padded-proposal retrieval role; do not substitute DINOv3 for DINOde.

This is an oracle-mask representation comparison, not detector-backed map retrieval or end-to-end VQA. ReplicaSSG test data contains relation triples but no aligned natural-language questions or answers; generated questions will be reported as a synthetic graph-query task. Earlier FP16 DINOv3 scores were invalidated after a CUDA diagnostic found non-finite embeddings. Only corrected FP32 scores are used. Test5 is complete: macro AP 0.036816, top-1 0.052632, top-5 0.256806 over 2,204 object observations. This is mask-isolated crop retrieval, not VQA or map association; controls lack per-view scores, pixel equivalence is unproven, and no paired significance test exists; upstream DINOde license is undeclared and assets remain local. T-REN point-conditioned region-text retrieval is measured on the frozen five-scene held-out split (macro AP 0.0246173, 2,204 views); it does not answer the separate DINOtxt global-crop substitution question. EOVSAM source/checkpoint are installed. The run2 completion produced 500 panoptic PNGs and hash-verified manifests (PQ 51.9504, SQ 80.2088, RQ 63.0339). Mask-fusion scoring is available (mask AP 0.3678 baseline); the scorer's exact segmentation-only projection independently verified AP, AP50, AP75, AP-small, AP-medium, and AP-large for baseline, replace, and union arms with maximum absolute delta 0.0. A fresh raw-pixel fusion reconstruction is unavailable because the run2 raw inference directory was removed. This optional panoptic benchmark does not validate ConceptGraphs mapping or replace the selected detector. ObjEmbed-2B and 4B both completed the frozen 250-view oracle-box experiment; their scores are mixed, and neither displaces the selected feature on this nonidentical crop protocol. SAM 3.1 completed on 100 paired COCO inputs using SDPA: mean mask IoU fell from 0.774529 to 0.589640, with 27 prompts returning no mask; keep this refinement disabled for the measured protocol. Native box and mask AP are measured for all four YOLOE-26 L/M segmentation and derived detect-only arms.
